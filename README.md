<h1 align="center">tropy-plugin-lists</h1>

Tropy plugin for importing folder structures as nested lists.

## Installation
* Download the `.zip` file from the [latest
release](https://github.com/tropy/tropy-plugin-example/releases/latest) on
GitHub.
* In Tropy, navigate to *Preferences… > Plugins* and click *Install
Plugin* to select the downloaded ZIP file.

## Usage
With the *Recreate lists* option enabled in Tropy settings, select 
*File > Import > tropy-plugin-lists* (or the name you assigned in the plugin settings) 
and pick a parent folder. Tropy will recursively import all supported 
files and assign them to lists mirroring the original structure.

## Plugin configuration
To configure the plugin, click its *Settings* button in *Preferences > Plugins*:
  - Choose a plugin *Name* that will show up in the *File > Import* menu (e.g. *Import as lists*).
